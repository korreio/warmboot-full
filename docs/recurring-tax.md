# Recurring tax

The default system has zero scheduled services, dashboards,
databases, telemetry, background agents, or network calls. The normal user flow
has zero installer commands: the bootstrap agent owns helper selection and
execution. Costs below occur only during agent work or maintenance of the small
source surface.

| Mechanism | Why it exists | Trigger | Owner | Recurring cost | Evidence | Deletion condition |
|---|---|---|---|---|---|---|
| One-time bootstrap-agent orientation | Let a fresh LLM understand the target and discover the relevant toolkit decisions before owning integration | First target adoption, or a materially changed toolkit version | Named bootstrap coordinator/agent | Read the small adoption/navigation core and target preflight once; bounded lanes load only decision-relevant templates, provenance, examples, capability cards or helper behavior; not paid on ordinary tasks | Orientation/lane receipts, target conflict/preservation report, and helper preview/installed inspection/check only when that integration shape remains plausible | Do not repeat until target ownership or toolkit behavior materially changes; delete this step only if a cheaper exercise proves the same integration judgment |
| Core plus routed context | Keep stable safety visible without blanket reading after integration | Ordinary target-agent startup; route selected only when needed | Project maintainer | Read a small loader/core and applicable route | `bin/warmboot check` for manifest-declared structure/content; installed-agent exercise | Delete an unused route in toolkit source. For a managed install, agent-own the reconciliation or rebootstrap so the manifest changes coherently; a direct deletion is a manifest mismatch. The self-declared manifest/`source_revision` do not prove authenticity or external provenance. |
| Preview/apply/check CLI | Supply deterministic secondary evidence for the agent-owned integration | Bootstrap agent invokes it after target preflight | Warmboot maintainer | One local stdlib process | CLI self-tests and acceptance prepare run | Replace only if a smaller inspectable repository-native path proves the same file invariants |

Optional project-document samples add no tax while omitted. If adopted or merged,
the target must name their owner and keep only entries that affect current operation,
user-visible history, defect recurrence, or a revisitable decision. Delete a sample
when its role moves to a stronger existing source of truth.
