# Example project instructions

Read the project README and current task before editing. Preserve unrelated work.
Use the project-owned setup and check commands. Keep each behavior with its owning
component and explain consequential choices beside the code.

Name one coordinator for Git and one holder for shared resources. A delegated worker
edits only its assigned paths and reports checks actually run, unresolved limits and
next steps. Independent review checks the changed sources before completion.

Package installation, remote publication and live data operations need explicit
authority. Stop when required input or authority is missing.
