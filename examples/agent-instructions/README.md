# Neutral instruction example

Short reusable, project-neutral operational instructions under MIT. Adapt the shared
`AGENTS.md` to the target's real commands and owners. `CLAUDE.md` only routes to it and adds no competing policy.

The filenames are adapters for tools that discover them. Another agent platform
can load the shared policy through its native entry mechanism. These files do not
install tools, create a task or grant publication authority.
