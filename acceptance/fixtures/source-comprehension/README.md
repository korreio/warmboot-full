# Source-comprehension acceptance fixtures

These tiny Java cases reproduce one failure class: plans and tests were strong while
production source stayed hard for a human to enter. The oracle checks only literal
evidence independently declared by these cases. It is not a Java parser,
comment-quality metric, comment counter, or generic target linter.

Real projects research and adopt their community's language-native form, then a
non-author reviewer reads every changed human-authored code file and judges whether
the source supplies useful orientation and applicable operative rationale.
